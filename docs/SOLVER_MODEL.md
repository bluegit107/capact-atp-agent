# SOLVER MODEL — S2.5 재기준화 이후 (PL-02 더마, 주 단위 LP/MIP)

범위: 더마(PL-02)·라인 L-02·52주. 기초(PL-01)·다품종(F2 이전)은 다음 슬라이스. 결과는 **아래 가정 하의 시뮬레이션 결과**다. 재기준화의 근거는 `REVIEW_2026-11-09.md`.

## 구조
`domain/solver_input.py` 입력·원시 결과 · `application/build_input.py` 계획 기준·조항·레버 → 입력(BuildModel) · `application/scenarios.py` 실행 조율 · `application/report.py` 재무·KPI·간트 후계산 · `application/economics.py` 단위 경제성·회수기간 · `adapters/solver_lp.py` OR-Tools(SCIP/HiGHS). LLM 없음, 결정론(같은 입력 → 같은 `input_hash`·결과).

## 계획 기준 (AS-001)
| 기준 | 능력 | 기존 부하 | 용도 |
|---|---|---|---|
| **S_MONTH (기본)** | `capacity_qty`를 월 능력으로 | 용량×가동률(97%)로 **주별 평준화**, 고객 구성비는 주별 수주 패턴 | 대회 문서(RFP·capex)와 정합 |
| S_YEAR | 연 능력으로 | 동일 | 대안(결론이 크게 달라짐 → 게이트) |
| H3 | 배치 로그 실측 ÷ 가동률 | 수주 규모 그대로 | 교차검증 |
| CONFIRMED | 담당자 확정 값 | 용량×가동률 | 생산기술 회신 후 |
- **규모 대응비** = 계획 기준 주간 부하 ÷ 수주 기준 주간 수요(S_MONTH에서 약 4.04). 수주·배치 규모 수량(편성 물량·회수 물량)에 곱한다(A05 §3).
- 주별 평준화가 필요한 이유: 수주일+60일 납기 패턴은 이미 출하된 주문이 빠져 앞 주차가 비어 보인다. 그대로 쓰면 가짜 여유 능력이 생겨 "증설 없이 100% 수락"으로 잘못 나온다(실제로 겪음, 뮤테이션 테스트로 고정).

## 수식
`S ≤ D`(선출하 금지) · `S + sh ≥ D[t−H]`(하드 지연 한도, 슬랙=최소 완화량) · `Lp ≥ D[t−grace] − S`(지체 비용) · `I[t] = I[t−1] + prod − Σx − bid` · `prod = base + overtime + option + outsourced` · 이진 옵션(선행 요건 확인된 것만) · 입찰 수락률 `a`, 공급 개시 후 4주 램프업. 하드 제약 위반 시 `INFEASIBLE`+최소 완화량.

## 비용·경제성
- **입찰 원가 = 원료 투입 원가/EA**(RFP 지시) = 43.0g × 170.2 USD/kg × 환율 → 환율에 연동(USD 원료). 실제 2026 상반기 투입원가 10,511원과 분해식 일치(±3%).
- 특근 할증 = (배수−1) × **가공비**(COGS/EA − 원료/EA = 2,308원). 외주 할증 = (배수−1) × 전체 단위원가(12,819원).
- **기대 리콜 비용/EA** = 12개월 확정 결함률(0.638%) × 입찰 단가(가정, 품질이 조정). 리콜 비용 공급자 전가 조건 반영.
- 경제성(`economics.py`): 환율 3종 × 단가 인하 0/−5/−10% 공헌이익 격자, 손익분기 인하율(원료 기준 약 −53%, 고정비 제외), 옵션 회수기간(사용 가능량 = min(추가 능력, 더마 부족분), 빠른 옵션부터 채움).

## 시나리오 (보호는 하드 제약)
| 안 | 정의 |
|---|---|
| Z | 입찰 없음, 기존 약속만 최선(Before). 누적 출하 = 기존 서비스 수준 |
| A | 서비스 수준 유지(하드) + 수락률 자유 → 부분 입찰. **동의 레버 사용 안 함** |
| B | 고객 동의(time_shift 레버)가 있는 고객만 동의한 주수만큼 늦출 수 있음(동의 구간 지체상금 없음). 동의 없으면 A와 같고 경고 |
| C | 입찰 100% + 서비스 수준 유지. 불가능하면 부족량 보고 |
| D | (참고) 보호 없이 지연 — 위약·위반 비용 비교용, 실행안 아님 |

## 레버·게이트
- **특근 기본 0**(근무형태 데이터 없음). `capacity_delta target="overtime:L-02"` 레버가 승인되면 반영(월 수량→능력 %, 시작 주, 가공비 배수). `BuildParams.overtime_cap_pct`는 what-if 전용이고 notes에 "확정 계획 아님"으로 남는다.
- 외주(`outsourcing:*`), 면책(`price_adjust clause:*`), 고객 동의(`time_shift customer:*`), 입찰 범위(`scope_change bid:*`). 그 밖은 '미지원'으로 notes에 남는다.
- 품질위원회 회수 의결 시 `recall_replacement_week` → 회수 대상 배치(B-02-2602-01·2603-01, 불량률 11.9%·11.6%, 311,478 EA × 규모 대응비)의 대체 생산을 4주에 걸쳐 같은 라인에 추가(가정).
- 지연 한도 = min(해지 트리거 −1주 여유, 지체상금 상한 소진 시점, 근거 없으면 8주). 편성 물량은 C-102 직전 4주 납기분에서 떼어내 W10 고정(이중 계상 없음).

## 현재 결과 (S_MONTH, 가정 하)
| 조건 | A 수락 | 비고 |
|---|---|---|
| 레버·회신 없음 | 66.7% | 증설·특근 없이 약 2/3. C는 불가능(부족 약 95만 EA) |
| C-101 납기 양해 7/14/21일(B) | 77.6% / 88.5% / 99.4% | **양해 1주당 약 +11%p**. A는 그대로 66.7% |

## 검증 (tests/test_solver.py 36건, 전체 143건)
골든 결론 회귀(S_MONTH 66.7%·OPT-02 시 100%·C 불가능, S_YEAR 5.5%) / 주별 부하 평준화 총량 / H3 규모 보존 / 특근 기본 0·레버 / 원가 환율 연동·실제 투입원가 일치 / 회수 의결 영향 / 물리 정합(4개 기준) / 편성 납기 / A·B·C 서비스 보호 / D 해지 트리거 미도달 / 동의는 B에만, 실제 효과(+5%p 이상) / HiGHS·SCIP 교차검증(불가능 해는 최소 완화량 합계로 비교) / 메타모픽 / 목적값=보고 재무 / 게이트·레버 / 경제성.
**뮤테이션 점검**: 부하 평준화 끄기 5건, 동의 하한 이동 끄기 1건, 원가 환율 연동 끄기 1건, 특근 15% 강제 6건 실패 → 원복 후 전부 통과.

## S3 — 게이트·프로브·레지스트리·사용자 시나리오
- **결정 불변성 게이트**(`application/gate.py`): S_MONTH·S_YEAR·H3(+확정값이 있으면 CONFIRMED)로 같은 시나리오를 풀어 (수락률, 조치, 실행 가능)을 비교. 수락률은 `invariance_accept_tol_pp`(기본 ±5%p, CEO/이사회만 변경) 안이면 같은 결정. 현재 결과: S_MONTH 66.7% / S_YEAR 5.5% / H3 39.3% → **결정이 기준에 좌우됨 → 상신 차단**. 생산기술이 "월 명목 능력"으로 회신하면(CONFIRMED=S_MONTH) 불변 → 해제. 증거는 `Assumption.tests`에 기록.
- **병목 프로브**(`application/probes.py`): 레버를 공짜로 넣어 다시 풀어 가치를 재고, 단위 가치로 협상 한계선을 만든다. 현재(A 기준, 가정 하):

| 협상 카드 | Δ순이익 | Δ수락 | 한계선 |
|---|---|---|---|
| 특근 월 3만 EA | +42.1억 | +32.2%p | 가공비 대비 할증 6.37배까지 이익 |
| 외주 월 5만 EA | +43.5억 | +33.3%p | 외주 단가 1.97배(전체 원가 대비)까지 이익 |
| C-101 양해 2주(B) | +28.5억 | +21.8%p | 1주당 14.2억 = 양해 대가 상한 |
| OPT-02 요건 회신(품질·구매) | +31.5억 | +33.3%p | 회신 전 6주·4주 가정 |
| C-201 부분 낙찰 허용 확인 | 87.0억 위험 | — | 전량 일괄이면 현재 능력으로 수행 불가 |
  문의 우선순위 = 가치 × 성공 가능성 ÷ 회신 소요일, 마감(21일)−3일 안에 회신 가능한지 표시. 성공 가능성·소요일은 모의 회신 정책표의 사전값(가정), 사내 특근은 2일·0.5 가정.
- **파라미터 레지스트리**(`domain/parameters.py`): 조작 가능한 가정 9개(지체율·지연 한도·해지 여유·램프업·편성 구간·회수 대체 기간/한도/비율·불변성 허용치). 값마다 단위·범위·출처·변경 가능 역할·체크포인트. **확정값은 사람·지정 역할만 변경**(버전·이력), AI는 `ProposedChange`만 만들고 적용은 사람. what-if는 범위만 검증하고 결과에 "확정 계획 아님" 표시(`settings_from_registry`).
- **사용자 정의 시나리오**: `ScenarioSpec`(보호·동의 사용·최소 수락·참고용 여부·가중치)을 E~Y ID로 추가, `only=`로 일부만 풀이.
- 검증: `tests/test_s3.py` 20건. 뮤테이션 5종(허용치 무시, 사람만 검사 제거, 역할 검사 제거, 양해 프로브를 A로 계산, 우선순위에서 성공 가능성 무시) 모두 실패 → 원복 후 통과.
